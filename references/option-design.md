# option-design.md — 选项卡片设计规范

选项卡片是本技能的核心交互件：让受访者"指认立场"而非"撰写答案"。设计质量直接决定数据质量。

## 硬性规则

0. **【阻断级】选项中立化三件套，缺一不可**（实测教训：草稿贴合项固定排在 A，导致受访者连续四轮选 A，等于让 AI 的猜测被确认了一遍）：
   - **乱序**：与草稿内容一致的"贴合项"**不得固定排在首位**（也不得固定排在任何固定位次），必须每轮变化其位置。
   - **逃逸项**：每题必须包含一个显式逃逸选项——`都不是／我的情况跟这些都不一样，我用自己的话说`。不得认为"负面选项"已足以替代逃逸项。
   - **报警**：若某受访者连续 ≥3 题选中贴合项，或连续 ≥2 轮全选贴草稿项，须在成稿的效度备注中写明"本稿存在选项顺从倾向，该题结论建议以自由陈述为准"。
1. **每题 2-4 个选项，每轮 ≤4 题。**
2. **每个选项 = 一个完整可指认的立场**，包含行为 + 理由，不接受单词式选项。
   - 差：`提高效率` / `降低成本`
   - 好：`从"做"变成"审"——取数算数做图的活基本没了，我主要看它对不对`
3. **选项集合必须覆盖负面立场**：未采用、更费力、没有变化、不敢用、基本不用。只给正面选项等于引导。
4. **选项之间互斥且覆盖光谱**：从"全自动依赖"到"完全不用"，从"自己拍板"到"必须找人确认"。
5. **保留自由通道**：始终告知受访者可直接用自己的话回答，自定义回答是最高价值数据。

## 四个选项的来源配比

设计一道题的选项时，按以下来源构建：

| 来源 | 作用 | 示例 |
|---|---|---|
| 认知基线中的行业共性 | 兜底"最大公约数"答案 | "回去问人，以人为准" |
| 锚点推断的个性化答案 | 贴合该受访者处境 | 对自研工具者给"改 Agent 配置固化进工作流" |
| 前一个受访者的意外答案 | 检验是否为共性 | 把 06 号的"业务自己都说不清的口径"变成下一人的选项 |
| 故意设计的"刺头"选项 | 激发纠正欲 | "其实没谁专门验，看着合理就先用着" |

第 3 条是跨案例研究的飞轮：每一位受访者的独特回答，都应该变成下一位受访者某道题的候选选项，用于检验该现象的普遍性。

## 题型与多选规则

- **单选**：用于定位、判据、采用情况等互斥维度。
- **多选（multiSelect）**：用于"补什么""变化有哪些""转交解释什么"等天然多项的维度。多选题最多 4 个选项。
- **自定义输入**：受访者选择 Other 并补充的说法，原话记录，成稿时优先于选项引用。

### 【影响级】必须在题面显式标注单/多选

实测教训：未标注时，受访者对"判断依据"这类天然多项的题直接答成 `A、B`，导致答案无法按单选归档。

- 每道题的题面必须带前缀标注：`（单选）` 或 `（可多选）`，不得省略。
- 答案回收格式也要写清：多选时说明"多个用逗号隔开"。
- 若受访者对标注为单选的题给出多个答案，**按实际采纳为多选**，并在成稿中标明该题应改为多选——同时回流修改问卷文件（见预测试修订回流规则）。

## 文本态出题模板（研究者中转通道专用）

本技能默认研究者坐在受访者身边中转题目（README 已说明），因此出题常以**纯文本**形式交付，而非 UI 卡片。此时必须遵守：

1. 每轮开头一句进度说明：`这一轮覆盖 Q3、Q4`。
2. 草稿预填段用引用块或明确标注，与题目区分。
3. 每题按以下格式给出：

   ```
   1）（单选）题干？
   A ……
   B ……
   C ……
   D 都不是／我的情况不一样，我用自己的话说
   ```

4. 指定回收格式：

   ```
   1：字母+补充
   2：字母+补充
   草稿纠正：<一句话，没有就写"草稿没问题">
   ```

5. **【影响级】部分作答检测**：回收答案时必须逐题核对。若有题未答、只答了部分题、或答案明显跑题，**必须就未答的题补问一次**，不得默认跳过、不得自行推断填空。实测中曾出现"一次给 4 题、只回收到 1 题"的情况。

## 题干措辞规范

- 题干必须包含具体情境锚点，不问抽象问题。
  - 差：`你怎么看待 AI 的价值？`
  - 好：`跟以前（不用 Agent 时）比，你自己做的工作最大的变化是？`
- 每轮开头用一句话点明这一轮覆盖问卷的哪几题（如"继续 Q3、Q4"），让研究者和受访者都知道进度。

## 草稿预填的写法

- 每轮先给 1-3 句草稿，用**受访者的口吻**写，敢于具体到可错。
- 草稿被全盘接受时，追问一句"有没有跟这个不一样的地方"——防止受访者图省事全盘点头。**连续 2 轮全盘接受即触发 `references/protocol.md` 的"重心转移"规则**（该场主答题已不产出原话，把时间投向追问）。
- 草稿被纠正时，纠正后的版本优先进入报告，并记录"我猜错了什么"——这是该受访者的区分度信息。

## 效度护栏（与 references/validity-notes.md 联动）

- 选项顺序随机化意识：不要把"期望答案"固定在第一个。
- 成稿时区分"选项确认"与"自发陈述"，论文引用优先使用自发陈述。
- 如果受访者对某题全部选项都不认可，该题标记为"未覆盖"，如实写入报告，不强行归类。
